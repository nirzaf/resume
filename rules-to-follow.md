### UI Design Guidelines Summary

#### **Core Principles**
- Design should be simple, clear, and user-centric.
- Ensure consistency across all devices.
- Maintain visually clean and intuitive designs. 

#### **Design Principles**
- **Functionality**: Ensure usefulness, practicality, and user needs.
- **Aesthetics**: Balance beauty with clarity and consistency.
- **Clarity**: Design intuitive, self-explanatory interfaces.
- **Subtlety**: Avoid distractions and focus on core functionality.
- **Attention to Detail**: Perfect typography, spacing, and responsive behavior.

## Code Standards
- ⚛️ Follow React + TS best practices
- 🧩 Maintain component modularity - Break into smaller focused components
- 📚 Write clean, documented code
- ⚠️ Implement proper error handling
- 🔄 Use proper Git commit messages

### Always follow these rules
- Always build the project after completing any task.
- Use the command: npm run build.
- Iterate until the build is successful.
- Push changes using git push if the build is successful.
